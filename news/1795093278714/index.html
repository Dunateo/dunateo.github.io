nginx2root:AI Discovers Five Critical nginx Flaws and a Path to Root

Vulnerability securityaffairs.com

  • CVE-2026-123007 Critical

Xint Research disclosed 'nginx2root', five critical vulnerabilities in nginx along with a Linux kernel SCTP bug, each accompanied by a proven exploit. The most severe flaw, CVE-2026-123007, sits in nginx HTTP/2 flow control and allows unauthenticated remote code execution on NGINX Plus or NGINX Open Source versions 1.9.5 through 1.31.8, which can be chained with the kernel flaw to gain root access. Fixed in version 1.31.9, the vulnerability affects nearly 10M Internet services according to Censys, with 98.9% of version-identified nginx servers appearing vulnerable in a 10 November Shodan scan, though no active attacks have been reported.

CISA Warns of 4 Exploited Flaws Linked to Ransomware, Cryptomining, and LLMjacking Attacks

Exploited Vulnerability Ransomware thehackernews.com

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added four actively exploited vulnerabilities to its Known Exploited Vulnerabilities (KEV) catalog on Wednesday. The flaws impact Synology DiskStation Manager (DSM), BerriAI LiteLLM, Apache Axis, and Vanderbilt University Research Electronic Data Capture (REDCap), and have been linked to ransomware, cryptomining, and LLMjacking attacks.

Apache Roller RCE Flaw CVE-2026-129448 Under Active Attack

Exploited Vulnerability securityaffairs.com

  • CVE-2026-129448 Critical
  • CVE-2026-82384 Critical

The Apache Software Foundation warned that attackers are actively exploiting CVE-2026-129448, a critical unauthenticated remote code execution vulnerability carrying a CVSS score of 9.8 in the open-source blogging platform Apache Roller. Affecting versions 4.0.0 through 6.1.4, the flaw stems from unsafe deserialization of vendor extension types in the XML-RPC endpoint prior to authentication, and expands the scope of an earlier September 2026 advisory tracked as CVE-2026-82384 that listed only version 6.1.5. Maintainers urge administrators to upgrade to Apache Roller 6.1.6 or later, or to disable extensions or remove the XML-RPC servlet mapping and restart the service.

F5 Warns 6 Critical BIG-IP Flaws Can Crash Traffic in Specific Setups, May Allow RCE

Vulnerability thehackernews.com

F5 disclosed six critical vulnerabilities in BIG-IP that allow unauthenticated attackers to crash the Traffic Management Microkernel (TMM) and disrupt network traffic until it restarts, and may allow remote code execution. Each flaw requires a specific virtual server configuration involving an iRule using a particular command or an APM policy containing two particular kinds of agent.

Hackers Breach N-able Cloud Server, Disrupting Email Security Management Across 3 Regions

Data breach thehackernews.com

N-able disclosed on Wednesday that unknown threat actors breached a server in its Mail Assure and Spam Experts Hosted Cloud, disrupting email security management across 3 regions. In response, the company disabled management interfaces and APIs while taking mitigation steps and continuing its investigation.

Law & policy Ransomware bleepingcomputer.com

Ukrainian authorities, working alongside the FBI, have arrested four suspected members of an international ransomware organization. The group is linked to more than $40.5 million in ransom payments collected from at least 28 companies worldwide.

Ruby Releases Fixes for 7 Regex and String Flaws, Warns 5 Have Proof-of-Concept RCE

Vulnerability thehackernews.com

Ruby maintainers released fixed versions to address seven memory-safety vulnerabilities in the language's regular expression engine and string case-conversion code. According to the project, proof-of-concept exploits demonstrate that crafted input can trigger remote code execution for five of the flaws.

PHP Warns of Critical Flaws Ahead of November Security Release

Vulnerability securityaffairs.com

  • CVE-2026-115560 TBD

The PHP development team announced an upcoming security release scheduled for 19 November 2026, between 14:00 and 14:30 UTC, to patch vulnerabilities across all supported versions. While the highest severity rating is CRITICAL, maintainers noted those issues require non-default configurations or uncommon setups and will publish technical details alongside the updates. One expected fix addresses CVE-2026-115560, a session handling remote code execution flaw separate from October's PHP2Shell vulnerabilities.
