SAP Security Incident: Stolen Tokens Raise Supply Chain Concerns

Supply chain securityaffairs.com

SAP has confirmed a security incident after detecting suspicious activity in its IT systems and said it took immediate steps to protect customers and secure its services. According to DER SPIEGEL, attackers stole employees' access tokens to alter and copy source code on GitHub, with an internal memo referring to the active investigation as 'Project Granite'. SAP has not confirmed reports that the attackers may have used AI agents and stated that investigators had found no evidence of unauthorized access to customer business data at that stage. The company has not disclosed how the tokens were stolen or which GitHub repositories were affected.

Drupal Warns of New Critical Flaw Exploited in the Wild

Exploited Vulnerability securityaffairs.com

  • CVE-2026-136716 Medium
  • CVE-2026-132165 Medium

Drupal warned of and fixed a highly critical vulnerability in Drupal Core, tracked as CVE-2026-136716, that attackers are actively exploiting to take over websites where the installer remains remotely accessible. Connected to the previously patched CVE-2026-132165 'Fail2Install' flaw from November 18, the issue leaves certain sites in unusual or incomplete installation states vulnerable following advisory SA-CORE-2026-017, without appearing vulnerable in the user interface. Maintainers released fixes in Drupal 11.4.14, 11.3.23, and 10.6.23, while warning that 11.0.x through 11.2.x and 10.5.x and earlier are end-of-life and will not receive updates. Administrators are urged to update, run update.php, secure install.php, and audit logs and the 'user 1' administrative account for signs of compromise.

North Korea-Linked PolinRider Poisons Over 7,600 GitHub Repositories to Spread Malware

Supply chain Malware APT thehackernews.com

Threat actors behind the North Korea-linked PolinRider campaign have compromised over 7,600 GitHub repositories to spread malware, in some cases planting a Python loader capable of delivering next-stage payloads. Evidence suggests the campaign may have begun as far back as February 2025. According to Apiiro researcher Shmulik Cohen, 6,541 of the 7,609 repositories, or 86%, belong to real developers rather than throwaway accounts.

FIFA Confirms a Cyberattack, Hackers Claim 12 GB of Internal Files

Data breach Ransomware securityaffairs.com

FIFA confirmed it suffered a cyberattack in which hackers accessed a limited set of personal and business information, and stated it is working closely with relevant authorities including law enforcement. A newly emerged ransomware and data-extortion group called the Handsome Boy Hacking Club, first observed in November 2026, claimed responsibility for the breach and alleged it took more than 12 GB of internal files from FIFA's Microsoft environment, including identity and immigration documents. The group listed FIFA on November 20 after listing Smith & Wesson, UCHealth, and Frontier Communications on November 19, bringing its publicly recorded claims to four, though its X account has since been suspended and its Tor leak site is unreachable. FIFA condemned the unlawful acquisition and publication of personal data, warning it could have serious consequences for affected individuals.

Unpatched Cacti Zero-Day Enables RCE in Just Four HTTP Requests via Guest Access

Vulnerability thehackernews.com

Details and a proof-of-concept exploit have emerged for an unpatched zero-day vulnerability in Cacti, an open-source network monitoring tool, that enables remote code execution. Tracked as 4HTTP2SHELL and 4HTTP2ROOT without an assigned CVE identifier yet, the flaw allows an attacker to achieve command execution from a fresh, unauthenticated HTTP session via guest access in four HTTP requests.

New NFS2ROOT Linux flaw can let attackers gain root privileges

Vulnerability bleepingcomputer.com

  • CVE-2026-99362 Critical

A 12-year-old critical vulnerability dubbed 'NFS2ROOT' has been disclosed in the Linux kernel's Network File System (NFS) server. Tracked as CVE-2026-99362, the flaw allows remote attackers to gain root privileges.

Hackers Trojanize Official Q-Dir and DesktopOK Downloads to Deliver Remote Access Malware

Supply chain Malware thehackernews.com

Cybersecurity researchers have disclosed a software supply chain attack in which threat actors tampered with Q-Dir and DesktopOK installation files distributed via the official SoftwareOK website to deliver remote access malware. Evidence indicates that malicious files were generated both during direct downloads from the official download page and during the update process of previously installed software.

Remus malware steals Gmail messages via fake Google Sheets extension

Malware bleepingcomputer.com

The Remus infostealer is stealing Gmail messages by using a stealthy malicious Chrome extension disguised as a fake Google Sheets extension. Operators behind the malware marketed this theft capability as a zero-day exploit in Google's email service.

Linux/EasyShell: MalwareMustDie Identifies One of the Earliest Publicly Documented RATs Built for LoongArch Linux

Malware securityaffairs.com

MalwareMustDie has documented Linux/EasyShell, a multi-platform Rust-based HTTPS beacon implant targeting Linux and macOS that provides shell access, file theft, credential plugins, SOCKS, and relay pivoting. Found via a shell script on a victim's node, the stager pulls payloads from a server in the United States over TCP port 8443 and installs a payload named polkitd across Linux and macOS, offering seven architecture builds including one of the earliest publicly documented RAT builds for LoongArch Linux. Researchers noted that the macOS and LoongArch payloads are framework defaults offered by every EasyShell stager rather than a targeted operator choice, and may not have been tested on real LoongArch hardware.
