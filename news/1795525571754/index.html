Hackers May Have Breached FBI Database Used by Police Nationwide

Data breach securityaffairs.com

The FBI is investigating a possible breach of the National Crime Information Center (NCIC) database used by police nationwide for arrest warrants and criminal records. The database contained more than 18 million active records across 22 databases and served over 100,000 law enforcement organizations as of 2023. Officials learned of the intrusion in recent days, but the timing, method, and perpetrators remain unknown. President Trump and Director of National Intelligence Jay Clayton have acknowledged the incident.

Database Leaks Expose 3.5 Billion Usernames, Passwords, and Documents

Data breach wired.com

A pair of unsecured databases exposed sensitive information about hundreds of millions of people, including data that could allow attackers to take over a victim’s digital life.

Microsoft Fixes Azure API Management Classic Flaw as Actor Targets Customer Secrets

Vulnerability thehackernews.com

Norway's National Security Authority disclosed that a security vulnerability in Microsoft Azure API Management (APIM) Classic tiers was exploited by an unknown actor to steal stored API credentials, affecting multiple businesses including energy companies Equinor and Skagerak Energi. The actor actively searched for access tokens, secrets, and named values in APIM.

South Korea’s power giant KEPCO confirms data breach impacting 1.5 million

Data breach bleepingcomputer.com

A threat actor breached the internal network of Korea Electric Power Corporation (KEPCO) and accessed two systems containing customer, employee, and contractor data, impacting 1.5 million individuals.

Webworm Suspected of Modifying SoftEther VPN to Evade Detection and Hide Remote Access

APT Malware thehackernews.com

The China-aligned threat actor Webworm is suspected of using a custom version of the open-source SoftEther VPN Bridge tool to evade detection and establish covert remote access to compromised networks. The modified variant implements various tricks to hide itself from security tools while disguising as network-monitoring software.

WHMCS SQL Injection Could Expose Customer Data and Admin Password Hashes without Login

Vulnerability thehackernews.com

A SQL injection flaw in WHMCS's shopping cart could allow anyone on the internet to retrieve customer records and administrator password hashes from the database without authentication. The company disclosed the vulnerability along with two other flaws requiring a logged-in client and released patches.

Critical binary-parser Flaw Enables JavaScript Injection via Malicious Parser Definitions

Vulnerability thehackernews.com

  • CVE-2026-134814 Critical

A critical code injection vulnerability in the binary-parser library (CVE-2026-134814, CVSS 9.2/8.1) allows an attacker who controls parser definitions to execute arbitrary code. The flaw affects binary-parser versions prior to 2.3.1.

McDonald’s Japan discloses breach exposing customer purchase and location data

Data breach therecord.media

McDonald’s Japan disclosed a cybersecurity breach that exposed customers’ purchase histories and mobile device location data.

Hangzhou Hikvision Digital Technology Co., Ltd. EZVIZ CS-C6N cloud snapshot improper certificate validation vulnerability

Vulnerability talosintelligence.com

  • CVE-2026-86587 High

An improper certificate validation vulnerability (CVE-2026-86587) in the EZVIZ CS-C6N cloud snapshot functionality allows a man-in-the-middle attacker to disclose sensitive information. The camera’s TLS configuration explicitly disables certificate verification, accepting any certificate during snapshot uploads.

Hangzhou Hikvision Digital Technology Co., Ltd. EZVIZ CS-C6N MQTT authentication bypass vulnerability

Vulnerability talosintelligence.com

  • CVE-2026-86586 High

An authentication bypass vulnerability (CVE-2026-86586) in the EZVIZ CS-C6N MQTT functionality allows an attacker to replay captured snapshot commands and trigger unauthorized camera snapshots. The MQTT link lacks TLS and the camera accepts verbatim replayed commands without nonce or timestamp checks.
