Hackers Exploit Critical Cisco Expressway Flaw, Breach Four Devices and Reach Internal Network

Exploited thehackernews.com

  • CVE-2026-76466 Critical

Threat actors have been observed exploiting a recently disclosed critical security flaw in Cisco Expressway to breach a Russian organization shortly after a proof-of-concept exploit was published. The vulnerability involves CVE-2026-76466 (CVSS score: 9.8), allowing an unauthenticated remote attacker with network access to compromise the device and reach internal networks.

Chaotic Eclipse Releases FastUnlock, a New Windows Zero-Day Vulnerability

Vulnerability securityaffairs.com

Chaotic Eclipse released FastUnlock, a new Windows zero-day vulnerability exploiting Narrator to bypass the lock screen. The researcher claims the flaw can bypass BitLocker encryption and allow code execution under the lock screen’s WsiAccount, having breached a fully encrypted Windows 11 26H2 system in just 5 minutes even with November security updates installed. The attack requires physical access to the computer and at least one user account linked to an online account, and can be triggered through the 'I forgot my PIN' or password option, with code execution achievable via Narrator navigation and a USB stick using the CAPS LOCK + Arrow keys/Enter/Space combination.

Hunt.io Uncovers Russian-Speaking Credential Theft Operation Targeting US Banks and Government Accounts

Malware securityaffairs.com

Hunt.io uncovered a credential-stealing operation that compromised 603 PCs and exposed bank, government and password manager accounts through an exposed open directory on a Netherlands VPS. The operation used three custom tools—HavoX, Phantom53 and Kraken Bridge—to manage infected devices, track victims and deliver tasks through temporary download links, resulting in more than 1.2 million connections across 603 computers communicating with command-and-control systems since October 12. Attackers recovered extensive credentials including 2,880 logins from one LastPass vault, 3,345 decrypted login records from Chrome and Edge databases, and bypassed Chrome’s app-bound encryption using hardcoded AES-GCM keys for Chrome versions 20 and 21.

JPMorgan Confirms Customer Data Breach Following Third-Party Compromise

Data breach infosecurity-magazine.com

JPMorgan has confirmed a customer data breach following a third-party compromise. Ransomware actor N0n has claimed attacks on JPMorgan, Visa and Mastercard, reportedly leaking customer data on its dark web site.

Linux KVM Flaw CVE-2026-99312 Lets Guest VMs Access Host Memory on AMD Hosts

Vulnerability thehackernews.com

  • CVE-2026-99312 High

A flaw in the KVM hypervisor, tracked as CVE-2026-99312, allowed researchers to read about 127 GB of a cloud server's memory from inside a virtual machine on DigitalOcean. The vulnerability affects only hosts with AMD processors and nested virtualization enabled, and on shared servers the memory may include other customers' virtual machines. Fixed kernels shipped.

ROMULUS ClickFix Attacks Deliver RAT That Can Spy on Users and Control PCs

Malware thehackernews.com

Threat actors have been observed using the ROMULUS ClickFix malware delivery platform to deliver a previously undocumented remote access trojan that shares similarities with CNCMachineRMS. The ROMULUS platform distributes CNCMachineRMS and Legion Loader through separate chains while retaining ClickFix and signed binary sideloading techniques.

ASUS warns of critical hard-coded key flaw in Control Center Express

Vulnerability bleepingcomputer.com

ASUS released Control Center Express v1.7.29 to fix three critical vulnerabilities that could let remote attackers gain administrative control of the management console and the devices it manages. The vulnerabilities permit unauthorized administrative access to the software and its managed devices.

Suspected North Korea-Aligned Group Hides C2 on Solana Blockchain

APT infosecurity-magazine.com

Cisco Talos has tied a remote access trojan to UAT-12643 that hides its command-and-control infrastructure on the Solana blockchain and survives Windows resets, attributing the technique to a suspected North Korea-aligned group. The RAT’s C2 resilience on Solana and Windows reset survival are noted as key features.

CyberPower PowerPanel Exploited to Run Malicious Code on Domain Controller

Malware infosecurity-magazine.com

Symantec discovered an attacker using CyberPower’s UPS software to run malicious scripts on a domain controller. The exploitation leverages the PowerPanel software to execute code within the compromised environment.
