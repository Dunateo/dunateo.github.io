Cairn AI Framework Used in Autonomous Zero-Day Exploitation

APT Exploited securityaffairs.com

Amazon threat intelligence identified autonomous AI agents running the Cairn framework without authentication, which independently discovered and exploited a zero-day vulnerability in an open-source medical imaging application to gain root access on university servers in East Asia. The operation, attributed to a Chinese-nexus actor, used prompts in Simplified Chinese and script timestamps configured to China Standard Time.

Microsoft Entra Connect Health flaw exploited to steal tenant data

Exploited Data breach bleepingcomputer.com

Microsoft warned organizations of a data breach resulting from the exploitation of a vulnerability in its Entra Connect Health service. Attackers gained unauthorized access to administrator email addresses and tenant configuration information.

Researchers Demonstrate Ghostscript Sandbox-Escape RCE via Crafted File Uploads in Popular Apps

Vulnerability thehackernews.com

Security researchers demonstrated that a now-patched flaw in Ghostscript allows a crafted file to escape the program's security sandbox and run commands on the server that processes it. Ghostscript is the interpreter that many Linux servers use to convert uploaded PDFs, PostScript files, and images into other formats, often without the application calling it directly.

Rackspace Spot breach let hackers access customer Kubernetes secrets

Data breach bleepingcomputer.com

Rackspace warned customers that hackers breached its Rackspace Spot cloud platform using compromised credentials, allowing them to deploy unauthorized workloads and access Kubernetes secrets in customer clusters. The attackers leveraged the breach to deploy unauthorized workloads within affected clusters.

BADBOX botnet returns with record-breaking 40 billion daily ad requests

Malware bleepingcomputer.com

The BADBOX malware has returned to large-scale ad-fraud operations, targeting a broad range of generic Android TV boxes. The campaign resumed following last year's disruptions.
