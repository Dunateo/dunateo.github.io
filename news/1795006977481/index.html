65 Characters to RCE: Inside the Java4Shell Vulnerability

Vulnerability securityaffairs.com

  • CVE-2026-114938 High

Calif researchers disclosed Java4Shell, a critical memory-corruption vulnerability tracked as CVE-2026-114938 with a CVSS score of 9.2 in OpenJDK's Base64 decoder. Triggered by a malformed padding string of 64 'A' characters plus an equals sign, or 128 on older OpenJDK 17, the x86-64 bug causes an out-of-bounds write past a 50-byte buffer. Calif demonstrated unauthenticated remote code execution in default settings of Keycloak, Atlassian Jira, Atlassian Confluence, JFrog Artifactory, Jenkins, and PingFederate, alongside authenticated RCE on Apache Kafka Broker, Apache Solr, Elasticsearch, Gerrit, and Spinnaker. Security patches are available and organizations are urged to update immediately.

Apache warns of Roller RCE vulnerability exploited in attacks

Exploited Vulnerability bleepingcomputer.com

Apache has released security updates to address a critical remote code execution flaw in Apache Roller. According to Apache, threat actors are exploiting the vulnerability in attacks to gain code execution on vulnerable servers.

Attackers Compromise Microsoft's Agent Framework PyPI Package to Steal Cloud Credentials

Supply chain Malware thehackernews.com

Threat actors compromised Microsoft's 'agent-framework' PyPI package to distribute a credential stealer, according to reports from Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket, StepSecurity, and Wiz. Malicious versions 1.26.1 and 1.26.2 were published 33 minutes apart on November 17, 2026, and are designed to run a cloud credential stealer on every Python start.

Fridge Controller Attacks: Researchers Find Six Zero-Days in an Hour

Vulnerability securityaffairs.com

Midnight Blue researcher Carlo Meijer found six unpatched pre-authentication remote code execution zero-day vulnerabilities in Danfoss AK-SM800A fridge controllers affecting all firmware versions up to and including 5.3.2. Five of the stack-based buffer overflows sit in unauthenticated web request handlers lacking basic exploit mitigations, while a sixth targets Danfoss Strict mode protections in an application that runs with root privileges. Successful exploitation could allow attackers to trigger defrost cycles, conceal logs, install persistent malware, or erase device memory. The disclosure follows ongoing attacks since 11 October against internet-exposed Danfoss and Copeland fridge controllers across Europe that have caused tens of millions of euros in spoiled food and fires.

U.S. CISA adds Perforce Puppet Enterprise flaw to its Known Exploited Vulnerabilities catalog

Vulnerability securityaffairs.com

  • CVE-2026-115731 High

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added a critical Perforce Puppet Enterprise vulnerability, tracked as CVE-2026-115731 with a CVSS score of 9.4, to its Known Exploited Vulnerabilities catalog. The flaw stems from improper deserialization of untrusted data in Puppet Server's report-processing component, enabling a client with a Puppet Certificate Authority-signed certificate to send a crafted HTTP PUT request and execute code as the Puppet Server service account. Perforce released patches on November 3, 2026, in Puppet Enterprise 2026.0.1, 2025.12.1, and 2023.8.13 as well as Puppet Core 9.1.3 and 8.22.2, noting it has no reports confirming active exploitation. CISA has ordered federal agencies to fix the flaw by December 1st, 2026.

Russian COLD RELIC Hackers Use Stolen Google Workspace Data to Breach Second U.S. Organization

APT Data breach thehackernews.com

Google's Mandiant and Threat Intelligence Group reported that the Russia-linked cyber espionage group Cold Relic, formerly COLDRIVER and UNC4057, used stolen Google Workspace data to breach a second U.S. organization. According to investigators reviewing the 2026 intrusion, the adversary weaponized an initial cloud compromise as a launchpad for linked third-party compromises.

Trigram Campaign Impersonates About 50 AI and Blockchain Brands to Target Devs with Infostealers

Malware thehackernews.com

Stormshield disclosed a large-scale campaign dubbed 'Trigram' targeting the artificial intelligence, blockchain, and logistics sectors across Europe and the U.S. The operation impersonates about 50 brands in the blockchain and AI sectors to trick developers into executing an infostealer themselves.

British Scattered Spider hacker sentenced to 6 years in prison

Law & policy bleepingcomputer.com

A British leader of the Scattered Spider cybercrime collective has been sentenced to six years in prison in the United States. The sentence stems from stealing millions in cryptocurrency and conspiring to hack a dozen companies.

Researchers hijack Hugging Face account for popular Kokoro AI model

Vulnerability Supply chain bleepingcomputer.com

A lack of ownership verification on the Hugging Face platform allowed security researchers to take control of the account hosting Kokoro, a popular text-to-speech AI model. The Kokoro model is used in projects from Google, NVIDIA, AMD, Intel, and Amazon Web Services.
