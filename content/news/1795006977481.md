<h2 class='story__title'><a href='https://securityaffairs.com/203387/hacking/65-characters-to-rce-inside-the-java4shell-vulnerability.html'>65 Characters to RCE: Inside the Java4Shell <span class='story__last'>Vulnerability</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-114938'>CVE-2026-114938</a> <span data-severity='High'>High</span></li></ul>
<p>Calif researchers disclosed Java4Shell, a critical memory-corruption vulnerability tracked as CVE-2026-114938 with a CVSS score of 9.2 in OpenJDK&#x27;s Base64 decoder. Triggered by a malformed padding string of 64 &#x27;A&#x27; characters plus an equals sign, or 128 on older OpenJDK 17, the x86-64 bug causes an out-of-bounds write past a 50-byte buffer. Calif demonstrated unauthenticated remote code execution in default settings of Keycloak, Atlassian Jira, Atlassian Confluence, JFrog Artifactory, Jenkins, and PingFederate, alongside authenticated RCE on Apache Kafka Broker, Apache Solr, Elasticsearch, Gerrit, and Spinnaker. Security patches are available and organizations are urged to update immediately.</p>
</section>

<section class='story' id='story-4'>
<h2 class='story__title'><a href='https://securityaffairs.com/203324/security/fridge-controller-attacks-researchers-find-six-zero-days-in-an-hour.html'>Fridge Controller Attacks: Researchers Find Six Zero-Days in an <span class='story__last'>Hour</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<p>Midnight Blue researcher Carlo Meijer found six unpatched pre-authentication remote code execution zero-day vulnerabilities in Danfoss AK-SM800A fridge controllers affecting all firmware versions up to and including 5.3.2. Five of the stack-based buffer overflows sit in unauthenticated web request handlers lacking basic exploit mitigations, while a sixth targets Danfoss Strict mode protections in an application that runs with root privileges. Successful exploitation could allow attackers to trigger defrost cycles, conceal logs, install persistent malware, or erase device memory. The disclosure follows ongoing attacks since 11 October against internet-exposed Danfoss and Copeland fridge controllers across Europe that have caused tens of millions of euros in spoiled food and fires.</p>
</section>
<section class='story' id='story-5'>
<h2 class='story__title'><a href='https://securityaffairs.com/203377/hacking/u-s-cisa-adds-perforce-puppet-enterprise-flaw-to-its-known-exploited-vulnerabilities-catalog.html'>U.S. CISA adds Perforce Puppet Enterprise flaw to its Known Exploited Vulnerabilities <span class='story__last'>catalog</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-115731'>CVE-2026-115731</a> <span data-severity='High'>High</span></li></ul>
<p>The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added a critical Perforce Puppet Enterprise vulnerability, tracked as CVE-2026-115731 with a CVSS score of 9.4, to its Known Exploited Vulnerabilities catalog. The flaw stems from improper deserialization of untrusted data in Puppet Server&#x27;s report-processing component, enabling a client with a Puppet Certificate Authority-signed certificate to send a crafted HTTP PUT request and execute code as the Puppet Server service account. Perforce released patches on November 3, 2026, in Puppet Enterprise 2026.0.1, 2025.12.1, and 2023.8.13 as well as Puppet Core 9.1.3 and 8.22.2, noting it has no reports confirming active exploitation. CISA has ordered federal agencies to fix the flaw by December 1st, 2026.</p>
</section>
