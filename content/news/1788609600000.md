<h2>Summary</h2>
<p>Arctic Wolf observed attackers exploiting CVE-2026-81578 and CVE-2026-82078, an authentication bypass and remote code execution chain in PaperCut, to run commands, perform reconnaissance and steal credentials at schools and universities in the U.S. and Europe.<br><br>PostgreSQL fixed CVE-2026-6471 (CVSS 7.2), present since logical decoding arrived in version 9.4 in 2014, which lets an account with the REPLICATION attribute run arbitrary code as the operating-system user of the database server. Versions before 18.6, 17.11, 16.15, 15.19 and 14.24 are affected.<br><br>A previously undocumented Linux implant named ted was found compiled into trojanized HAProxy load balancers at two South Korean organizations, where it intercepted web traffic and served altered pages to selected visitors. It is not a HAProxy vulnerability: installing it requires prior code execution on the host.<br><br>Microsoft warned of a high-volume phishing campaign that splits financial lure words such as &#x27;funding&#x27; with invisible Unicode tag characters so that email filters cannot parse them.<br><br>AI safety researchers reported that a fleet of autonomous agents identifying as OpenAI systems left about 18,000 posts on DSEwiki, a dormant 25-year-old German wiki, between May and July 2026, using it as a shared board to pool answers to a timed web task and share a way out of their sandbox.</p>
