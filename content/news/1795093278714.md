<h2 class='story__title'><a href='https://securityaffairs.com/203440/hacking/nginx2rootai-discovers-five-critical-nginx-flaws-and-a-path-to-root.html'>nginx2root:AI Discovers Five Critical nginx Flaws and a Path to <span class='story__last'>Root</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-123007'>CVE-2026-123007</a> <span data-severity='Critical'>Critical</span></li></ul>
<p>Xint Research disclosed &#x27;nginx2root&#x27;, five critical vulnerabilities in nginx along with a Linux kernel SCTP bug, each accompanied by a proven exploit. The most severe flaw, CVE-2026-123007, sits in nginx HTTP/2 flow control and allows unauthenticated remote code execution on NGINX Plus or NGINX Open Source versions 1.9.5 through 1.31.8, which can be chained with the kernel flaw to gain root access. Fixed in version 1.31.9, the vulnerability affects nearly 10M Internet services according to Censys, with 98.9% of version-identified nginx servers appearing vulnerable in a 10 November Shodan scan, though no active attacks have been reported.</p>

<section class='story' id='story-3'>
<h2 class='story__title'><a href='https://securityaffairs.com/203419/security/apache-roller-rce-flaw-cve-2026-129448-under-active-attack.html'>Apache Roller RCE Flaw CVE-2026-129448 Under Active <span class='story__last'>Attack</span></a></h2>
<p class='story__tags'><span class='nb nb--exploited' title='Exploited in the wild or zero-day: attackers already use it.'>Exploited</span> <span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-129448'>CVE-2026-129448</a> <span data-severity='Critical'>Critical</span></li><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-82384'>CVE-2026-82384</a> <span data-severity='Critical'>Critical</span></li></ul>
<p>The Apache Software Foundation warned that attackers are actively exploiting CVE-2026-129448, a critical unauthenticated remote code execution vulnerability carrying a CVSS score of 9.8 in the open-source blogging platform Apache Roller. Affecting versions 4.0.0 through 6.1.4, the flaw stems from unsafe deserialization of vendor extension types in the XML-RPC endpoint prior to authentication, and expands the scope of an earlier September 2026 advisory tracked as CVE-2026-82384 that listed only version 6.1.5. Maintainers urge administrators to upgrade to Apache Roller 6.1.6 or later, or to disable extensions or remove the XML-RPC servlet mapping and restart the service.</p>
</section>
