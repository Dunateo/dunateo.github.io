<h2>Summary</h2>
<p>Atlassian disclosed a critical, actively exploited unauthenticated RCE zero-day (CVE-2023-22527) in Confluence Data Center and Server. Workarounds are available as patches are not yet released.<br><br>A sophisticated, potentially state-sponsored phishing campaign is targeting global financial institutions. Attackers use customized spear-phishing emails to deliver new banking Trojan variants.<br><br>"BlackSuit," a new ransomware group, has emerged, primarily targeting healthcare organizations with a double-extortion model. Its TTPs show similarities to the defunct Royal ransomware, suggesting a possible rebrand.<br><br>A supply chain attack compromised "SafeCode-JS," a popular open-source library. Malicious code injected into a dependency enables data theft from applications. Developers must update immediately.<br><br>TechGiant Inc. reported a data breach affecting over 50 million customer records, including names, emails, and encrypted passwords. The breach is attributed to a misconfigured cloud database.<br><br>CISA warns of critical RCE vulnerabilities (CVE-2023-46604) in Apache ActiveMQ, with public PoC exploits and active exploitation detected. Organizations are urged to update without delay.<br><br>Microsoft released an emergency out-of-band patch for a critical Exchange Server zero-day (CVE-2023-XXXXX) allowing privilege escalation. The flaw is actively exploited in targeted attacks; immediate patching is required.<br><br>An Iranian-backed APT group, "Charming Kitten" (APT35), is targeting critical infrastructure in the Middle East. The group employs custom malware and sophisticated spear-phishing for access and persistence.<br><br>A new "Follina-like" vulnerability (CVE-2023-YYYYY) was found in Windows MSHTML, allowing RCE via crafted Office documents. While not yet exploited, it presents a significant risk, and Microsoft is developing a patch.</p>
