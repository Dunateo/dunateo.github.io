<h2>Summary</h2>
<p>N-able released Hotfix 4 for its N-central remote monitoring and management platform, its fourth hotfix in five weeks, to fix an unauthenticated remote code execution flaw. Every on-premises build below 2026.3.1.14, including servers updated to Hotfix 3 a day earlier, needs it. N-able&#x27;s incident notice says the flaw has been exploited in the wild, while its release notes call that unconfirmed.<br><br>A security researcher published a zero-day exploit for CrowdStrike that could allow attackers to escalate privileges.<br><br>The Rhysida ransomware group published data stolen from the Berlin state government after a €2 million extortion demand was refused. The dataset reportedly includes Berlin state employee data and highly sensitive emergency plans.<br><br>TantoSec published a working proof-of-concept that turns an AES-CBC padding oracle in Telerik UI for ASP.NET AJAX into unauthenticated remote code execution. It only works against applications in a specific non-default configuration, Progress patched the chain in July, and no exploitation in the wild has been confirmed.<br><br>Sekoia and Kudelski Security observed that North Korea&#x27;s Lazarus umbrella is split into six distinct clusters focused on espionage, financial theft and sanctions evasion.<br><br>Huntress described worm-like activity abusing ConnectWise ScreenConnect to push a four-stage VBScript payload to newly connected hosts. Three unrelated incidents used different initial access methods, including a Quick Assist tech-support scam and a phishing-delivered MSI installer.<br><br>Check Point Research analyzed JSCeal, a compiled V8 JavaScript malware with credential harvesting, surveillance and traffic-interception capabilities that can bypass Google authentication with stolen session cookies. Its payloads are protected with RC4-encrypted strings, control-flow flattening and other obfuscation layers.<br><br>Several victims of a recent breach of driver&#x27;s license information have filed class action lawsuits against IDScan, the company they believe responsible.</p>
