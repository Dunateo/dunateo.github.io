<h2>Summary</h2>
<p>Palo Alto Networks Unit 42 retracted its earlier assessment that an attack on a European government agency involved the PHP2Shell flaws, saying it targeted a vulnerable PHP application. Exploitation attempts against PHP2Shell continue amid suspected North Korean global scanning activity.<br><br>Microsoft issued an emergency update for a critical buffer overflow in .NET, fixing two newly disclosed vulnerabilities as well as flaws not fully addressed in an earlier release.<br><br>A researcher showed that unpatched Tailscale SSH flaws let a single hacked device on a Tailscale network gain root access to other servers it can reach, provided Tailscale SSH allows port forwarding and the network&#x27;s access rules permit the connection.<br><br>Wasmtime maintainers fixed two critical flaws that could let a malicious WebAssembly module escape its sandbox when compiled by a vulnerable build; one of them affects only ARM64 systems.<br><br>Wiz detailed Gheist, an automated campaign that uses stolen GitHub tokens to plant workflows printing a repository&#x27;s secrets into GitHub Actions logs, downloading them and deleting the runs. It has succeeded against private repositories and GitHub Enterprise environments.<br><br>Huntress observed a Microsoft 365 campaign between July 14 and September 22, 2026 that used an adversary-in-the-middle relay to capture sign-in sessions and replay the stolen tokens, compromising 97 accounts at 79 organizations.<br><br>Forever Security caught a malicious instruction file in a developer&#x27;s Downloads folder that tried to make an AI coding agent install a known-malicious npm package; the agent was stopped before any code ran.<br><br>Researcher Ovi found uCreator, a rentable Android spyware kit hidden in tampered copies of Telegram and WeChat distributed outside official stores. It can steal Telegram two-factor passwords and clone WeChat accounts; its Telegram component matches the Baohuo backdoor.<br><br>A researcher published a second persistent Secure Boot bypass for the Chromecast with Google TV (4K).</p>
