<h2>Summary</h2>
<p>Microsoft&#x27;s October Patch Tuesday fixed a record 1,413 vulnerabilities, including an actively exploited Windows Shell bug. The release covers 1,102 Windows flaws, 134 in Office, 61 in developer tools, 36 in SharePoint Server and 22 in SQL Server; more than 670 are privilege escalation bugs.<br><br>Volexity said on October 13 that an attacker chained three Ivanti Connect Secure zero-days to run commands as root without logging in. Ivanti has fixed two of them and urged customers to act immediately; the fix for the third is still pending.<br><br>SAP disclosed a CVSS 10.0 flaw in its Cloud SDK for Python that can send an application&#x27;s OAuth2 client credentials to an attacker-controlled server. It affects multi-tenant applications on SAP Business Technology Platform and requires the attacker to control the tenant subdomain.<br><br>Docker fixed on September 30 a two-year-old Docker Hub flaw in the account-to-organization conversion feature that let one user push, pull or delete images as another user. Docker found no evidence of exploitation.<br><br>Tencent Zhuque Lab found Vghost (CVE-2026-74580), a flaw in the Linux kernel&#x27;s vhost subsystem present for nearly a decade that lets a local user read and write kernel memory and become root. In one virtualization setup, an untrusted virtual machine can write to host memory and hijack the program running it.<br><br>GitHub now expires unvalidated npm trusted publishing configurations 48 hours after creation, after researchers showed that an attacker could publish new versions of another user&#x27;s package without stealing credentials, leaving more than 1,500 packages exposed to hijacking.<br><br>XBOW researchers chained three previously unknown Google Chrome bugs into a full-chain exploit that runs code on Windows when a user simply loads a web page, building it in six days with AI agents running OpenAI&#x27;s public GPT-5.6 Sol model. Google confirmed and fixed all three bugs and paid a $250,000 bounty.<br><br>Several European retail firms confirmed cyber incidents, while H&amp;M said it is investigating such claims.<br><br>ThreatFabric detailed Hirudo, a new Android banking trojan that replaces legitimate banking apps, including eight Indonesian ones, with patched versions designed to bypass the apps&#x27; own built-in security checks.<br><br>Norway&#x27;s data protection authority fined Microsoft-owned advertising unit Xandr a record €8.6 million ($9.62 million) for illegally relaying Grindr users&#x27; sensitive data, which can reveal sexual orientation, to advertisers.</p>
