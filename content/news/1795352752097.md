<section class='story' id='story-1'>
<h2 class='story__title'><a href='https://securityaffairs.com/203664/ai/cairn-ai-framework-used-in-autonomous-zero-day-exploitation.html'>Cairn AI Framework Used in Autonomous Zero-Day <span class='story__last'>Exploitation</span></a></h2>
<p class='story__tags'><span class='nb nb--apt' title='Nation-state or advanced persistent threat actor.'>APT</span> <span class='nb nb--exploited' title='Exploited in the wild or zero-day: attackers already use it.'>Exploited</span> <span class='story__source'>securityaffairs.com</span></p>
<p>Amazon threat intelligence identified autonomous AI agents running the Cairn framework without authentication, which independently discovered and exploited a zero-day vulnerability in an open-source medical imaging application to gain root access on university servers in East Asia. The operation, attributed to a Chinese-nexus actor, used prompts in Simplified Chinese and script timestamps configured to China Standard Time.</p>
</section>
<section class='story' id='story-2'>
<h2 class='story__title'><a href='https://www.bleepingcomputer.com/news/security/microsoft-entra-connect-health-flaw-exploited-to-steal-tenant-data/'>Microsoft Entra Connect Health flaw exploited to steal tenant <span class='story__last'>data</span></a></h2>
<p class='story__tags'><span class='nb nb--exploited' title='Exploited in the wild or zero-day: attackers already use it.'>Exploited</span> <span class='nb nb--breach' title='Data stolen, leaked or exposed.'>Data breach</span> <span class='story__source'>bleepingcomputer.com</span></p>
<p>Microsoft warned organizations of a data breach resulting from the exploitation of a vulnerability in its Entra Connect Health service. Attackers gained unauthorized access to administrator email addresses and tenant configuration information.</p>
</section>
<section class='story' id='story-3'>
<h2 class='story__title'><a href='https://thehackernews.com/2026/11/researchers-demonstrate-ghostscript.html'>Researchers Demonstrate Ghostscript Sandbox-Escape RCE via Crafted File Uploads in Popular <span class='story__last'>Apps</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>thehackernews.com</span></p>
<p>Security researchers demonstrated that a now-patched flaw in Ghostscript allows a crafted file to escape the program&#x27;s security sandbox and run commands on the server that processes it. Ghostscript is the interpreter that many Linux servers use to convert uploaded PDFs, PostScript files, and images into other formats, often without the application calling it directly.</p>
</section>
<section class='story' id='story-4'>
<h2 class='story__title'><a href='https://www.bleepingcomputer.com/news/security/rackspace-spot-breach-let-hackers-access-customer-kubernetes-secrets/'>Rackspace Spot breach let hackers access customer Kubernetes <span class='story__last'>secrets</span></a></h2>
<p class='story__tags'><span class='nb nb--breach' title='Data stolen, leaked or exposed.'>Data breach</span> <span class='story__source'>bleepingcomputer.com</span></p>
<p>Rackspace warned customers that hackers breached its Rackspace Spot cloud platform using compromised credentials, allowing them to deploy unauthorized workloads and access Kubernetes secrets in customer clusters. The attackers leveraged the breach to deploy unauthorized workloads within affected clusters.</p>
</section>
<section class='story' id='story-5'>
<h2 class='story__title'><a href='https://www.bleepingcomputer.com/news/security/badbox-30-botnet-returns-with-record-breaking-40-billion-daily-ad-requests/'>BADBOX botnet returns with record-breaking 40 billion daily ad <span class='story__last'>requests</span></a></h2>
