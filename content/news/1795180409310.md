<h2 class='story__title'><a href='https://thehackernews.com/2026/11/hackers-exploit-critical-cisco.html'>Hackers Exploit Critical Cisco Expressway Flaw, Breach Four Devices and Reach Internal <span class='story__last'>Network</span></a></h2>
<p class='story__tags'><span class='nb nb--exploited' title='Exploited in the wild or zero-day: attackers already use it.'>Exploited</span> <span class='story__source'>thehackernews.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-76466'>CVE-2026-76466</a> <span data-severity='Critical'>Critical</span></li></ul>
<p>Threat actors have been observed exploiting a recently disclosed critical security flaw in Cisco Expressway to breach a Russian organization shortly after a proof-of-concept exploit was published. The vulnerability involves CVE-2026-76466 (CVSS score: 9.8), allowing an unauthenticated remote attacker with network access to compromise the device and reach internal networks.</p>
</section>
<section class='story' id='story-2'>
<h2 class='story__title'><a href='https://securityaffairs.com/203537/hacking/chaotic-eclipse-releases-fastunlock-a-new-windows-zero-day-vulnerability.html'>Chaotic Eclipse Releases FastUnlock, a New Windows Zero-Day <span class='story__last'>Vulnerability</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>securityaffairs.com</span></p>
<p>Chaotic Eclipse released FastUnlock, a new Windows zero-day vulnerability exploiting Narrator to bypass the lock screen. The researcher claims the flaw can bypass BitLocker encryption and allow code execution under the lock screen’s WsiAccount, having breached a fully encrypted Windows 11 26H2 system in just 5 minutes even with November security updates installed. The attack requires physical access to the computer and at least one user account linked to an online account, and can be triggered through the &#x27;I forgot my PIN&#x27; or password option, with code execution achievable via Narrator navigation and a USB stick using the CAPS LOCK + Arrow keys/Enter/Space combination.</p>
</section>
<section class='story' id='story-3'>
<h2 class='story__title'><a href='https://securityaffairs.com/203554/cyber-crime/hunt-io-uncovers-russian-speaking-credential-theft-operation-targeting-us-banks-and-government-accounts.html'>Hunt.io Uncovers Russian-Speaking Credential Theft Operation Targeting US Banks and Government <span class='story__last'>Accounts</span></a></h2>
<p class='story__tags'><span class='nb nb--malware' title='Malware family, campaign or tooling.'>Malware</span> <span class='story__source'>securityaffairs.com</span></p>
<p>Hunt.io uncovered a credential-stealing operation that compromised 603 PCs and exposed bank, government and password manager accounts through an exposed open directory on a Netherlands VPS. The operation used three custom tools—HavoX, Phantom53 and Kraken Bridge—to manage infected devices, track victims and deliver tasks through temporary download links, resulting in more than 1.2 million connections across 603 computers communicating with command-and-control systems since October 12. Attackers recovered extensive credentials including 2,880 logins from one LastPass vault, 3,345 decrypted login records from Chrome and Edge databases, and bypassed Chrome’s app-bound encryption using hardcoded AES-GCM keys for Chrome versions 20 and 21.</p>
</section>

<section class='story' id='story-5'>
<h2 class='story__title'><a href='https://thehackernews.com/2026/11/new-linux-kvm-flaw-cve-2026-99312-lets.html'>Linux KVM Flaw CVE-2026-99312 Lets Guest VMs Access Host Memory on AMD <span class='story__last'>Hosts</span></a></h2>
<p class='story__tags'><span class='nb nb--vulnerability' title='A security flaw, its disclosure or its patch.'>Vulnerability</span> <span class='story__source'>thehackernews.com</span></p>
<ul class='story__cves'><li><a href='https://vulnerability.circl.lu/vuln/CVE-2026-99312'>CVE-2026-99312</a> <span data-severity='High'>High</span></li></ul>
<p>A flaw in the KVM hypervisor, tracked as CVE-2026-99312, allowed researchers to read about 127 GB of a cloud server&#x27;s memory from inside a virtual machine on DigitalOcean. The vulnerability affects only hosts with AMD processors and nested virtualization enabled, and on shared servers the memory may include other customers&#x27; virtual machines. Fixed kernels shipped.</p>
</section>
<section class='story' id='story-6'>
<h2 class='story__title'><a href='https://thehackernews.com/2026/11/romulus-clickfix-attacks-deliver-rat.html'>ROMULUS ClickFix Attacks Deliver RAT That Can Spy on Users and Control <span class='story__last'>PCs</span></a></h2>
