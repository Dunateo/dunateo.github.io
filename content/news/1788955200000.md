<h2>Summary</h2>
<p>Microsoft&#x27;s September Patch Tuesday fixed a record 974 vulnerabilities, including two actively exploited Windows zero-days. The release covers 723 flaws in Windows, 111 in Office, 62 in SQL and 22 in developer tools, with more than 110 rated critical.<br><br>Google patched 230 Chrome vulnerabilities, including CVE-2026-87491, an actively exploited out-of-bounds write in the V8 engine that enables code execution inside the sandbox.<br><br>SAP fixed CVE-2026-44756 (CVSS 10.0), a memory corruption flaw in SAP Extended Passport (EPP) processing in the SAP kernel that allows unauthenticated remote code execution.<br><br>Sophos reported that malware linked to break-ins at F5 BIG-IP Access Policy Manager appliances injects a PHP web shell into memory whenever Apache loads one of three of the appliance&#x27;s own PHP scripts, so checks of the files on disk come back clean.<br><br>The researcher known as Chaotic Eclipse released a proof-of-concept for ShieldCrash, a new Microsoft Defender zero-day assessed as a bypass of the patch for ShieldBreak (CVE-2026-69414, CVSS 7.8), which the researcher reported last month.<br><br>Check Point Research showed that a single instruction planted in a ChatGPT conversation could make ChatGPT secretly work for an attacker while answering the user normally. In its proof of concept, it read data from the victim&#x27;s connected Gmail account and passed it to a second ChatGPT account through a hidden channel.<br><br>Google Threat Intelligence Group observed a financially motivated group using an autonomous, multi-agent AI attack framework to run a large-scale credential harvesting campaign that compromised thousands of credentials in under six hours.<br><br>CrowdStrike is tracking Slim Spider, a previously undocumented Brazil-based financially motivated actor targeting Brazilian financial institutions since at least March 2026 and stealing crypto custody secrets, showing deep knowledge of the country&#x27;s financial infrastructure, including its instant payment system.<br><br>The attackers who took nearly 4,000 bitcoin from the Liquid Network on September 6 by exploiting an Elements bug returned 3,400 of it the next day, but about 598.5 bitcoin is still missing. The Bitcoin sidechain remains paused, so L-BTC holders cannot redeem their tokens.<br><br>cPanel patched a flaw affecting every supported version of cPanel and WHM that lets an authenticated hosting account with mail privileges create arbitrary files through EmailTrack and run code as root, taking over the entire server.</p>
